# Report Issues & File Complaints {#report-issues}

If you have an issue, concern, or complaint related to Vue.js, this page will help you find the right channel to get the help you need.

## Types of Issues {#types-of-issues}

### 🐛 Bug Reports {#bug-reports}

If you've found a bug in Vue.js itself or any of the official packages:

**Where to report:** [Vue.js GitHub Issues](https://github.com/vuejs/core/issues)

**What to include:**
- Clear description of the bug
- Steps to reproduce the issue
- Expected vs actual behavior
- Vue version and environment details
- Minimal reproduction example (using [Vue Playground](https://play.vuejs.org))

**Other repositories:**
- Vue Router bugs: [Vue Router Issues](https://github.com/vuejs/router/issues)
- Pinia bugs: [Pinia Issues](https://github.com/vuejs/pinia/issues)
- Vite bugs: [Vite Issues](https://github.com/vitejs/vite/issues)

### 💡 Feature Requests {#feature-requests}

For suggesting new features or improvements:

**Where to request:** [Vue.js RFCs Repository](https://github.com/vuejs/rfcs)

Major changes require an RFC (Request for Comments). For smaller features, you can also use [GitHub Discussions](https://github.com/vuejs/core/discussions).

### ❓ Getting Help {#getting-help}

If you need help with your Vue.js code or have questions:

- **[Vue.js Forum](https://forum.vuejs.org/)** - Best for detailed questions and community support
- **[Discord Chat](https://discord.com/invite/vue)** - Real-time help and community discussion
- **[Stack Overflow](https://stackoverflow.com/questions/tagged/vue.js)** - Q&A with the `vue.js` tag
- **[GitHub Discussions](https://github.com/vuejs/core/discussions)** - Community discussions and help

### 🚨 Code of Conduct Violations {#conduct-violations}

For reporting harassment, inappropriate behavior, or Code of Conduct violations:

**Contact:** [community@vuejs.org](mailto:community@vuejs.org)

All reports are handled confidentially and investigated promptly. See our full [Code of Conduct](/about/coc) for details.

### 📚 Documentation Issues {#documentation-issues}

For problems with the Vue.js documentation:

**Where to report:** [Vue Docs GitHub Issues](https://github.com/vuejs/docs/issues)

You can also edit documentation pages directly by clicking the "Edit this page on GitHub" link at the bottom of any documentation page.

### 🌐 Translation Issues {#translation-issues}

For issues with translated versions of the documentation:

Check the [translations page](/translations/) for links to the specific translation repositories and their issue trackers.

### 🛡️ Security Issues {#security-issues}

For reporting security vulnerabilities:

**Contact:** [security@vuejs.org](mailto:security@vuejs.org)

Please do not report security issues in public GitHub issues. We follow responsible disclosure practices.

### 🏢 Ecosystem & Third-Party Issues {#ecosystem-issues}

For issues with third-party Vue.js libraries, tools, or components:

Contact the maintainers of those specific projects. Most Vue ecosystem projects have their own GitHub repositories with issue trackers.

## Response Times {#response-times}

- **Critical bugs and security issues:** Usually reviewed within 24-48 hours
- **Regular bug reports:** Typically reviewed within a few days to a week
- **Feature requests:** May take longer as they often require community discussion
- **Community support:** Response times vary depending on community availability

## Before You Report {#before-reporting}

1. **Search existing issues** to avoid duplicates
2. **Check the documentation** - your question might already be answered
3. **Try the latest version** - your issue might already be fixed
4. **Create a minimal reproduction** - this helps maintainers investigate faster

## Getting Faster Help {#getting-faster-help}

- **Be specific** in your reports and questions
- **Include relevant details** like Vue version, browser, and error messages
- **Use clear titles** that describe the issue
- **Be patient and respectful** - maintainers are volunteers
- **Consider sponsoring** the project if it's valuable to your business
